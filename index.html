Profile Scan

1. Photograph the part

  1. Lay the part flat on a sheet of plain white paper, at least ¼ inch from every edge.
  2. Put the paper on a darker table so its edges stand out.
  3. Hold the phone straight above, level with the table, with all four paper corners in view.
  4. Use soft, even light such as shade or an overcast day. Avoid hard shadows.

What this does

Profile Scan uses the paper as a ruler. It straightens the photo, finds the part's outline and holes, and turns them into true lines, arcs and circles. It saves a DXF file (a standard CAD drawing format) that SolidWorks opens as a sketch, ready to extrude.

It's for flat parts: brackets, plates, gaskets, templates. Expect about ±0.01 inch on a good photo; check critical dimensions with calipers.

2. Check the paper corners

Drag the red dots onto the four corners of the paper, if they aren't there already. A magnifier appears while you drag.

Adjust

Slide right if the part outline is missing pieces. Slide left if shadows or marks are being picked up.

Thick parts look slightly bigger to the camera than they really are. Enter both numbers and the app corrects for it.

Save for SolidWorks

"Share" lets you AirDrop or email it to the computer that runs SolidWorks. "Save" puts it in the Files app.

Opening it in SolidWorks
  1. File → Open, set the file type to DXF (*.dxf), and open the file.
  2. In the DXF/DWG Import box, choose Import to a new part as 2D sketch, then Next.
  3. Set the units to Inches and tap Finish.
  4. Select the sketch and use Extruded Boss/Base with the part's thickness.
  5. If the extrude complains, Tools → Sketch Tools → Check Sketch for Feature points to any gap.

The outline is drawn as connected lines, tangent arcs and circles, with the part's lower-left corner at the origin. Add dimensions and relations in SolidWorks as you would for any sketch.
